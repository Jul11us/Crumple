The same paper. A new desktop.

Crumple 来到 Windows。延续 macOS 版的雾灰、牛皮纸与深色外观，以及揉纸、投篓和打印小票的整理手感。

### 下载与安装 / Download

适用于 **Windows 10 / Windows 11，x64**。程序自带运行环境，无需另装 .NET。

| 文件 | 用途 |
| --- | --- |
| `Crumple-1.1.1-Windows-x64-Setup.exe` | 安装向导，创建开始菜单入口与系统卸载入口。 |
| `Crumple-1.1.1-Windows-x64.exe` | 免安装单文件程序。 |
| `Crumple-1.1.1-Windows-SHA256SUMS.txt` | 两个 exe 的 SHA-256 校验值。 |
| `Crumple-1.1.1-Windows-NOTICES.txt` | 随包组件许可。 |

### 可以做什么 / Included

- 检查用户临时文件、浏览器缓存、日志、开发缓存、安装包与旧下载。
- 空间分析、大文件查找与完整 SHA-256 重复文件比对。
- 拖起文件，揉成纸团，投进纸篓；查看清理小票并恢复已记录的项目。
- 查看系统读数、桌面应用与启动项；通过 Windows 及应用自己的流程完成维护和卸载。
- 简体中文、English，以及与 macOS 版一致的三套外观。

Cleanup uses the Windows Recycle Bin. Installers, old downloads and developer caches start unselected. Files still occupy disk space until the Recycle Bin is emptied. The Windows preview does not provide permanent deletion.

### 预览版说明 / Preview status

已通过 22 项核心测试、Avalonia 界面渲染和演示拖拽检查、Windows x64 交叉编译与安装包完整性检查。界面与交互检查在 macOS 上完成。

This is an **unsigned preview**. Windows system integration—including the real Recycle Bin, registered uninstallers, startup items and audio—has not yet been validated on a Windows machine. This release is marked as a prerelease to reflect that verification scope.
