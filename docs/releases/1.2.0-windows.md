Crumple 1.2.0 把 AI 工具留下的文件归到一处，让整理继续保持清楚、从容。

### 这一版 / What's new

- **AI 工具残留**：智能清理增加独立分类，检查 Claude、Cursor、Windsurf 的网页缓存，以及 Claude Code、Codex 等工具的相关文件。
- 可重新生成的缓存默认勾选；运行时、模型和对话记录只列出，不自动选择。
- 对话记录按项目展示，可以单独选择是否清理。
- 保留关联进程保护、路径边界、忽略列表和清理前文件变更检查。

### 下载与安装 / Download

适用于 **Windows 10 / Windows 11，x64**。两种 exe 均自带运行环境，无需另装 .NET。

| 文件 | 用途 |
| --- | --- |
| `Crumple-1.2.0-Windows-x64-Setup.exe` | 安装向导，创建开始菜单入口与系统卸载入口。 |
| `Crumple-1.2.0-Windows-x64.exe` | 免安装单文件程序。 |
| `Crumple-1.2.0-Windows-SHA256SUMS.txt` | 两个 exe 的 SHA-256 校验值。 |
| `Crumple-1.2.0-Windows-NOTICES.txt` | 随包组件许可。 |

Cleanup uses the Windows Recycle Bin. Files continue to occupy disk space until the Recycle Bin is emptied. This preview does not provide permanent deletion.

### 预览版说明 / Preview status

23 项核心测试通过，包含新增的 AI 文件默认选择检查。随包提供 SHA-256 校验文件。

This is an **unsigned preview**. Core tests, interface rendering and demo interactions are checked on macOS. Windows system integration—including the real Recycle Bin, registered uninstallers, startup items and audio—has not yet been validated on a Windows machine.
