Less left behind.

把 AI 工具留下的，整理清楚。Crumple 1.2.0 为新的工作习惯留出空间，也让每次打开文件列表更轻快。

### 这一版 / What's new

- **AI 工具残留**：在智能清理里单独查看 Claude、Claude Code、Codex、Cursor、Windsurf、Gemini CLI、Ollama 与 LM Studio 的相关文件。
- 缓存默认勾选；运行时、虚拟机镜像、模型和对话记录只列出，留给你选择。工具运行时会保护其文件，清理前再次检查。
- Claude Code 对话记录按项目列出；能够确认原项目路径已经不存在时，会加上标记。
- AI 工具的缓存归入独立分类，避免与开发缓存重复列出。
- **列表更轻快**：文件图标改为后台读取，扫描结束前预取首批图标，减少列表出现时的等待。

### 下载与安装 / Download

下载 **`Crumple-1.2.0-macOS-universal.dmg`**，打开镜像，将 Crumple 拖入「应用程序」。适用于 **macOS 14+**，同时包含 Apple 芯片与 Intel 版本。

Scanning is read-only. Selected cleanup items move to the Trash by default. Files continue to occupy disk space until the Trash is emptied.

### 验证 / Verification

38 项 Swift 测试通过，包含新增 AI 文件默认选择、运行中保护、项目路径识别和分类去重检查。随包提供 SHA-256 校验文件。

This build is ad hoc signed and has not been notarized by Apple. Runtime and interface checks are performed on an Apple silicon Mac; the Intel slice is cross-compiled.
