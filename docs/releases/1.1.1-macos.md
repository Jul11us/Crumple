A little less clutter. A little more space.

Crumple 把整理空间变成一个轻巧的日常动作：拖起文件，揉成纸团，轻轻投进纸篓。清理结束，一张小票记下每次取舍。

### 下载与安装 / Download

**`Crumple-1.1.1-macOS-universal.dmg`** — 适用于 macOS 14+，同时支持 Apple 芯片和 Intel。打开镜像，将 Crumple 拖入「应用程序」。

### 这一版 / In this release

- 雾灰、牛皮纸与深色三套外观，简体中文与 English。
- 智能清理、空间分析、大文件与完整 SHA-256 重复文件比对。
- 原生纸团投掷、纸篓与明确选择的碎纸机模式。
- 清理小票、记录与撤销；空格预览、⌘Z 撤销、停止扫描和键盘快捷键。
- 实时系统状态、菜单栏面板、应用关联文件与维护工具。

Scanning is read-only. Cleanup moves selected files to the Trash by default. Recycled files continue to use disk space until the Trash is emptied. Tracked items can be restored while they remain in the Trash and their original paths are free.

### 验证 / Verification

本机通过 33 项 Swift 测试、中英文本地化检查、Apple 芯片与 Intel 通用构建及 DMG 完整性检查。校验文件：`Crumple-1.1.1-macOS-SHA256SUMS.txt`。

This build is ad hoc signed and has not been notarized by Apple. Native runtime checks were performed on an Apple silicon Mac; the Intel slice is cross-compiled.
