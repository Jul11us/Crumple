# Crumple 界面调整 · 2026-10-31

本次设计审查与工作流程参考 **unslop by Damir Sokolovsky ([@heydamir](https://x.com/heydamir))**，来源：<https://github.com/heydamir/unslop>，许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。以下是面向 Crumple 原生 SwiftUI 界面的适配记录。

## 方向

- 产品：帮助 Mac 用户查看磁盘空间并清理文件
- 气质：安静、准确、有一点趣味
- 材质：浅纸色、墨色文字、纸张与金属纸篓
- 重点：磁盘用量、扫描操作，以及文件变成纸团的过程
- 标志细节：揉纸投篓与清理后打印的小票

## 审查

- `PageBackground`：大面积彩色光晕与底部色带，削弱内容对比
- 侧边栏：每页一色的渐变图标、过多单项分组，导航层级偏重
- 按钮：彩色发光、渐变胶囊与大型圆形扫描按钮，主次不够清晰
- 概览：问候语占据主标题，工具重复成六张相同卡片
- 字体：粗体、圆体和零散的半点字号混用，数字格式缺乏统一
- 扫描首页：插画、标题与按钮垂直堆叠，横向空间利用不足
- 图表：部分统计、分类图表与装饰使用过多颜色
- 插画：纸张与纸篓属于产品，但外部光晕、闪星与闲置漂浮不解释状态
- 浅色默认：未设置外观时跟随系统，与本次用户要求不一致

## 九轮调整

1. 间距：侧栏 240，导航行 36，页边距 32–40，主要分区间距 24；工具改为统一行高的双列列表
2. 色彩：中性纸色背景、不透明表面、三种文字角色；灰绿色用于主操作与选中状态，警告和错误保留独立语义色
3. 图标：统一使用 SF Symbols，导航 17、主要工具 18；移除彩色图标底板
4. 文案：概览直接命名页面；权限提示与扫描说明缩短；删除“只要几秒钟”的时间承诺
5. 字体：保留原有品牌标志；页面标题采用系统字体中等字重，常用数字使用等宽数字
6. 布局：磁盘与清理入口保持不等宽；工具集中为一张分隔列表；扫描首页文字与纸篓并排
7. 细节：按钮半径 8、主要卡片 16，选中导航使用细标记；设置快捷键独立为键帽
8. 视觉：保留原有纸篓、文件和清理小票；移除背景光晕、插画闪星与发光徽章；无需生成图片
9. 动效：悬停只改变表面，普通按钮轻按反馈；静态首页插画不再闲置漂浮，实际揉纸、投掷和小票动画继续表达清理过程

首次启动默认浅色；用户已保存的浅色、深色或跟随系统选择继续生效。

## 验证入口

`swift test` 检查现有安全与扫描行为；`bash scripts/build.sh` 同时构建 arm64、x86_64 并提取本地化资源；`bash Localization/verify.sh` 检查中英文资源。

`--render-interface` 仅在 `CRUMPLE_DEMO_HOME` 模式下工作，通过未显示的原生宿主窗口渲染实际 SwiftUI 视图，包含 ScrollView。输出浅色 1180×780 与深色 1100×720 的概览、智能清理、大文件、重复文件和应用卸载预览。
